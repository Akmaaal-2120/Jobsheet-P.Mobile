Install Android studio

* download dan install android studio
* klik next terus
* setelah selesai, install Android SDK command line



install Flutter

* download dan extract file flutter 
* masukkan folder bin ke dalam environment variable
* lalu masuk ke cmd dan ketik flutter doctor untuk mengecek apakah sudah terinstall semua



setup vscode

* install extension flutter dan dart
* buat file dart lalu pilih console application



tugas yang diberikan adalah membuat rumus segitia dan dapat dijalankan

= cara menjawabnya adalah membuat rumus segitiga di folder lib dan masukkan rumusnya di method yang ada lalu jangan lupa buat parameter di methodnyya agar bisa kita input dan setelah selesai baru kita run untuk mengecek hasilnya
